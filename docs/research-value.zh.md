# Lab Calc 的研究与学习价值

> 面向：需要用这个工具做实验、写论文、准备复试的人。
> 本文只写代码里能验证的事实。凡是"本工具不保证"的地方都明确写出，因为一个看起来权威、实则按理想溶液计算的结果，会被信任到超出它应得的程度。

---

## 一、它解决的问题

实验室里最重复、最容易出错、又最不值得占用脑力的三件事：

1. **算配制量**——"要配 500 mL 0.5 mol/L NaCl，称多少克？"
2. **算稀释**——"从 1 mol/L 母液稀释到 0.1 mol/L，取多少毫升？"
3. **算完就忘**——三天后想知道"上次那个缓冲液到底怎么配的"，记录本上没写。

第三件事最要命。计算本身不难，难的是**可追溯**：论文方法学部分要写清楚实际配制浓度，复现实验要能回查当时用的参数，导师问"你这个浓度怎么来的"要能立刻答上。

Lab Calc 的定位是**带记忆的计算器**：每次计算自动留存，可重算、可导出、可打印成报告贴进实验记录本。它不替代实验记录本，它是记录本上"配制方法"那一栏的草稿。

## 二、每个计算用的是什么算法

下表列出各计算模块实际实现的公式。**这些是代码里写的公式，不是理想化的教科书描述**——两者的差别在"局限性"一节。

| 模块 | 计算 | 实现的公式 |
|------|------|-----------|
| `solution.mjs` | 摩尔质量 | 按元素原子量求和；支持水合物（`CuSO4·5H2O`）与括号 |
| `solution.mjs` | 称量配制 | m = C · V · M |
| `solution.mjs` | 稀释 | C₁V₁ = C₂V₂，同时给出需加溶剂量 |
| `buffer.mjs` | 缓冲液配比 | Henderson–Hasselbalch：pH = pKa + log([A⁻]/[HA]) |
| `buffer.mjs` | 梯度稀释 | 逐级等比递推，输出每级浓度与体积 |
| `titration.mjs` | 弱酸 pH | 近似式 [H⁺] ≈ √(Ka·C) |
| `titration.mjs` | 弱碱 pH | 近似式 [OH⁻] ≈ √(Kb·C) |
| `titration.mjs` | 百分比浓度 | w/v% = C · M / 10 |
| `titration.mjs` | 滴定等当点 | n(待测物) = n(滴定剂) 的化学计量点 |
| `colligative.mjs` | 依数性 | ΔTb = i·Kb·m，ΔTf = i·Kf·m，π = iMRT |
| `electro.mjs` | 电池电动势 | Nernst 方程，E = E° − (RT/nF)·lnQ |
| `reaction.mjs` | 反应计量 | 配平校验 + 限量试剂判定 + 理论产量 |
| `reagent.mjs` | 浓试剂换算 | 由质量分数与密度求摩尔浓度；当量浓度、质量摩尔浓度、摩尔分数 |
| `reagent.mjs` | 离子强度与活度系数 | **Davies 方程**：log₁₀γ = −A·z²·(√I/(1+√I) − 0.3·I) |
| `reagent.mjs` | 分光光度 | Beer–Lambert：A = εcl，含标准曲线线性回归 |
| `lab.mjs` | 实验台计算 | 菌落计数 CFU/mL、核酸 A260/A280 纯度、master mix |
| `curve.mjs` | 滴定曲线 | 逐点求解，自动定位等当点 |

### 物理常数

代码中使用的常数（`src/calc/colligative.mjs`、`src/calc/electro.mjs`）：

| 常数 | 取值 | 说明 |
|------|------|------|
| 气体常数 R | 8.314462618 J/(mol·K) | CODATA 2018 精确值 |
| 气体常数 R | 0.08205736608096 L·atm/(mol·K) | 渗透压用 |
| 法拉第常数 F | 96485.33212 C/mol | CODATA 2018 精确值 |

### 依数性常数

Kf / Kb 用的是标准表列值（水 Kf=1.86、Kb=0.512 K·kg/mol 等），共 8 种常见溶剂。这些是**文献值**，不是本工具测量的。

## 三、结果是怎么验证的

**750 个自动化测试**（36 个测试文件）+ **15 项对已知答案的冒烟检查**。

验证方式分三层：

1. **单元测试**——每个计算函数对已知答案断言。例如 0.1 mol/L 乙酸（pKa 4.76）的 pH 必须是 2.88。
2. **冒烟检查**（`npm run verify`）——15 项覆盖各模块的数值断言，每次构建前跑。
3. **浏览器渲染测试**——jsdom 挂载全部 15 个标签页与所有模式，捕获只有运行时才暴露的错误（历史上出现过"构建成功但页面空白"）。

**必须说明的**：这些测试验证的是**代码忠实实现了上表的公式**，不是验证公式本身适用于你的体系。前者是工程问题，后者是化学问题，本工具不能替你回答。

## 四、什么情况下结果不可靠

这一节是本文最重要的部分。

### 1. 活度修正只在"浓试剂"标签页，且只到 I ≈ 0.5 M

这一条需要说准确，因为容易误解：

- **`reagent.mjs` 实现了 Davies 方程**修正活度系数，`ionicStrength()` 由离子列表计算 I。I = 0.1 时一价离子 γ ≈ 0.78，即有效浓度比形式浓度低 22%——足以让缓冲液 pH 偏移零点几。
- **但这是"浓试剂"标签页的功能，不是全局默认。** 溶液配制、缓冲液、pH 等标签页仍按理想溶液（γ = 1）计算。**如果你需要活度修正，必须显式走浓试剂页。**
- **Davies 适用范围约 I ≤ 0.5 M**，覆盖常规实验，但**不适用于海水或浓盐溶液**。代码注释里写明了这一点。

其余理想化假设：

- **温度**——所有常数按 25 °C 取值，未做温度补偿。
- **CO₂ 溶解**——敞开体系放置的碱液会吸收 CO₂，实际浓度低于计算值。
- **体积收缩**——乙醇+水等体系混合后体积小于两者之和。
- **杂质与纯度**——按 100% 纯度计算；实际试剂需按标签纯度折算。
- **CO₂ 溶解**——敞开体系放置的碱液会吸收 CO₂，实际浓度低于计算值。
- **体积收缩**——乙醇+水等体系混合后体积小于两者之和。
- **杂质与纯度**——按 100% 纯度计算；实际试剂需按标签纯度折算。

**具体影响**：0.1 mol/L 乙酸用近似式得 pH 2.88，精确解约 2.87，差 0.01；但 1 mol/L 时近似式误差会到 0.1 以上。**浓度越高，本工具的偏差越大**，这正是浓试剂页提供活度修正的原因。

### 2. 滴定曲线在等当点附近是近似值

等当点附近的 pH 由水的电离主导，近似式在该区间失效。曲线在那里是示意性的，**不能用来精确读取等当点 pH**。

### 3. 强酸强碱、极稀溶液不适用近似式

代码会在这些情况下给出警告（界面上显示为黄色提示），但**警告不代表结果可用**，只代表"我知道这里有问题"。

### 4. 数据来源的边界

元素周期表的物理性质（密度、熔点、沸点、电负性、第一电离能）来自 **PubChem**。118 个元素中有相当一部分数据缺失——密度只有 96 个元素有值，电负性 95 个，沸点 93 个。

**缺失值在界面上显示为"无数据"（em dash），不会填 0。** 热力图上缺失的元素画成空白格而不是最低值色——因为"没测过"和"最低"是两回事，把前者画成后者是在断言一个没人测过的数。

## 五、和商业工具比

| 维度 | Lab Calc | 商业实验室软件（如 ChemDraw / LabArchives） |
|------|----------|---------------------------------------------|
| 价格 | 免费、开源（MIT） | 订阅制，年费数百至数千元 |
| 数据归属 | 只存在你自己浏览器里，不上传 | 云端账户，条款允许厂商访问 |
| 离线 | 完全可用（PWA 安装后） | 多数需联网 |
| 化学深度 | 基础：溶液、缓冲、滴定、计量、电化学 | 深度：结构式、谱图、反应预测、合规审计 |
| 合规 | **无任何合规认证** | 部分通过 FDA 21 CFR Part 11 等 |
| 适用场景 | 教学、日常配制、快速估算 | 生产、法规申报、正式实验记录 |

**结论**：Lab Calc 不是商业软件的替代品，也不打算是。它替代的是"拿计算器按一遍然后忘掉"这个流程。**有法规要求、需要审计追踪的场景，请用合规软件。**

## 六、对论文与复试的实际用途

### 写论文时

- **方法学部分**：导出的 Excel 表格可直接作为配制记录附在补充材料里。
- **可复现性**：JSON 备份文件包含完整输入输出，换电脑可继续，三年后能查。
- **数据整理**：Excel 导出每个输入输出独占一列，可直接排序、筛选、作图；CSV 是扁平的五列格式，适合快速粘贴。

### 准备复试时

- **口算校验**：面试问"配 500 mL 0.5 M NaCl 称多少"，心算 0.5×0.5×58.44 ≈ 14.6 g，与工具结果对照。
- **公式理解**：每个计算都有"计算过程"面板，列出代入的每一步，不是只给答案。
- **单位换算**：内置换算表，避免 mol/L ↔ g/L ↔ % 之间手算出错。

### 不该用它的时候

- 正式实验记录本上，**以你自己手写的记录为准**，本工具只是草稿。
- 需要审计追踪、电子签名、法规合规的场景。
- 高浓度（>0.1 mol/L）且需要精确 pH 的场合——请用带活度修正的软件或实测。

## 七、技术上的可验证性

如果要把本工具的结果写进论文，以下是可核验的：

```bash
git clone https://github.com/acrot0/lab-calc
cd lab-calc
npm install
npm test          # 750 个测试
npm run verify    # 15 项已知答案检查
```

- **公式在代码里**：`src/calc/*.mjs`，每个函数上方注释写明公式与理由。
- **测试在 `test/`**：每个断言对应一个具体数值。
- **版本可追溯**：每次提交都有说明，构建版本号显示在页脚。
