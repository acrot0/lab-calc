## 本次修复的两个静默缺陷

**Windows 桌面版一直是白屏。** 自引入代码分割以来，每个发布的桌面包都是死的：应用能打开、显示标题和背景色，但什么都不画。两个原因叠加，单元测试都看不见——它们只在 `file://` 下失败。打包脚本会去掉 `type="module"`（`file://` 拒绝模块脚本），而剩下的 bundle 里仍含 `import.meta`，那在非模块脚本里是**语法错误**，整个脚本解析失败。`import.meta` 来自 Vite 自己的 preload 辅助函数，关掉代码分割也不会消失。现在桌面构建产出 IIFE。打包脚本会拒绝含 `import.meta`、动态 `import(` 或多于一个 JS 文件的产物——失败现在落在构建期，而不是用户的第一次启动。

**手机上计算器基本没法用。** 390×844 实测：按键 40px（低于 44px 底线）、DEG/RAD 48×28、单位 chip 28px，360×640 下 42 个键只有 25 个够得到。而且 sheet 锚在 `bottom: 0` 却完全不知道软键盘存在——没有任何视口单位能反映它，因为键盘是覆盖在页面上而不是改变页面尺寸——输入框还会在打开时自动聚焦，把键盘召唤到键盘区上方。横屏手机（844×390）能过宽度断点，于是拿到浮动窗，而浮动窗的边界钳制只保证「抓取边距」在屏幕内——这对光标能拖回来的窗口是对的，对拇指拖不回来的窗口是错的；实测那里 42 个键一个都够不到。

## 新增

- **pH 页做活度校正**。缓冲液页做了而 pH 页没做，读起来像是 README 小心避开的一个声明。现在两个模型并排显示。校正需要两个 pKa 不携带的量——酸型电荷与背景离子强度——两者默认值都让校正归零，所以不知道离子强度的用户拿到的还是原来的答案。实测 I = 0.1：磷酸 pKa₂（z = −1）4.100 → 3.993，铵（z = +1）5.125 → 5.232，乙酸（z = 0）2.880 → 2.884。那个 0.004 如实报告：中性酸的各项相消，理想模型是对的，硬造一个可见偏移教的是错机理。
- **反应计量页新增产量曲线**。数字回答「我能得到多少」，回答不了「再加这个有没有用」。答案是平台段，而平台段在一行结果里看不出来。扫过一遍就是一条在化学计量比处拐平的折线——4 Fe 对 3 O₂ 是一个线拐弯的地方，不是一个要背的事实。
- **示意图可导出独立 SVG**。组件自己的注释声称图「可以复制标记来导出」，这是不成立的：每个形状都通过 CSS 类上色，而类又解析到主题 token，所以标记本身是没有样式的黑色细线。导出会读取每个元素的计算样式并写回元素上。
- **Android APK**，从同一份 web bundle 构建。实测 4.5 MB，对比 Electron 的 268 MB——同一个应用。启动图标是本应用自己的标记（五个密度桶 + 自适应前景），版本读仓库的 `package.json` 而不是 Capacitor 模板的 `1.0`。
- **Tauri 外壳**作为另一条桌面构建路径。
