## 这一版解决的是「数据会不会丢」

不是新功能，是三条会让实验结果消失、或者让你以为结果很准的路。

### 删除不再是抹除

以前点删除、点「全部清除」，记录就没了——没有确认，没有回收站，也没有痕迹。写论文的时候这意味着：一次误触，一组数据消失，而且你是在需要它的那天才发现。

现在删除是**标记**：记录离开列表，留在文件里，设置里能看到「已删除 N 条」并逐条或一次性恢复。导出的 JSON 备份包含已删除的记录——否则「导出备份、清空、再导入」这个流程会把你想保住的东西正好丢掉。

### 结果不再假装自己很准

`14.61 g` 是用万分之一天平称的。以前应用会把这个数写到四五位，而天平根本撑不起那些位数。

现在称量和稀释两个页签的结果下面会给**不确定度**，展开可以看每一项的来源和贡献：

| 来源 | 贡献（0.5 mol/L NaCl，500 mL A 级容量瓶） |
|---|---|
| 容量瓶允差 | 0.029% |
| 氯化钠摩尔质量 | 0.017% |
| 天平 | 0.001% |
| **合成** | **0.034%** |

数字不是估的：允差取自 ISO 1042 / ASTM E288（容量瓶）和 ISO 648 / ASTM E969（移液管）的 A 级限，按矩形分布换算成标准不确定度（GUM 4.3.7、Eurachem QUAM:2012 §8.1.4）。天平的分度值按半宽算，线性允差按称量两次计——皮重和毛重各一次，漏掉会让不确定度小 41%。

面板里明写**没算进去的东西**：手法（定容、读数、温度平衡）、试剂纯度、吸湿性。真实的不确定度通常比这个大，这句话比数字本身重要。

### 桌面版可以自己更新了

以前装完之后想升级只能重新下载安装包。现在设置面板里有「检查更新」，之后的版本自动升级。

更新包是签名的，公钥编译在程序里，签名不匹配的包会被拒绝安装。私钥在 GitHub Secrets，不在仓库里。

**这一版的更新通道要等下一个版本才能验证**——先装 0.9.1，等 0.9.2 发布时点一次检查更新就知道了。
