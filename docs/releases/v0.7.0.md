## 计算之后多两张图

判据是**图能不能改变结论**，不是图好不好看。只把数字重画一遍的图，是读那个数字更慢的方式。

### pH 计算：各质子化态的分布

这一页建立在 `[H⁺] ≈ √(Ka·C)` 上，而这个近似式有适用范围——它假设酸几乎不解离。看过分布曲线的人，不用别人告诉就知道公式什么时候还能用。

图上有两件公式藏起来的事：

- 两条曲线**恰好**在 pH = pKa 处相交
- 到 pKa + 2 时酸型只剩不到 1%，而那时近似式早已失效

页面本来就挂着同样的警告。这张图是把那句警告变成**可以自己核对**的东西。

各形态按**次序**着色，不按身份：一套配色只有几种能分辨的色相，而磷酸有四个质子化态——按身份着色需要生成器，还会产出两种没人分得清的绿。次序本身就是信息，所以色阶跟着次序走，名字交给图例（用 DOM 而不是画进画布，任何缩放下都能读，读屏软件也够得着）。

### 电化学：Nernst 直线

E 随 Q 对数变化，所以真正要问的通常不是「现在 E 是多少」，而是「Q 还能动多远，电池才不再推动反应」。画出来，那段距离是看得见的；列成表，它是一个读者得自己解出来的数。

斜率是 RT·ln10/nF，所以**线的陡峭程度就是这一页设定的 n 和温度**。改温度或改 n，线绕 lg Q = 0 转动——四个独立的结果行表达不了这个关系。

**横轴只取工作点两侧各一个数量级，不会为了画到 E = 0 而拉长。** 第一版拉长了，理由是「交点才是重点」。对大多数电池不成立：lg₁₀K = nE°/0.05916，丹尼尔电池（E° = 1.1 V、n = 2）在 lg Q ≈ 37 才到平衡，画 38 个数量级会把线压成一条缝，95% 的画布是空的。

所以交点在窗口内才画；不在时图注改说「这支电池离平衡太远（lg K = 37.3），横轴取不到 E = 0——所以画出来的是斜率本身」。**标记出现，就意味着「你离平衡在一个数量级以内」**——这是电池的性质，不是坐标轴的偶然。

## 顺带

`niceTicks` 挪到 `chart-axis.mjs` 并支持非零最小值。第二张图需要它，而另一个选择是从一个绘图组件里 import 坐标轴助手——那会让第二个图依赖第一个图的文件，理由跟两张图都没关系。

Nernst 的 y 轴正需要非零这一支：一个数量级的窗口里电势只移动百分之几伏，旧的从零起算的刻度序列会把每个刻度都放到绘制范围之外。
