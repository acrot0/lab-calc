## 1.4.0：它长出了一个实验台

上一版为止，这是一个有二十页的计算器：算得准、留得住、能导出。这一版
它开始回答另一些同样每天要问的问题——**我的试剂在哪、过期了没有、
台上还压着几个计时、我昨天算到哪了**。

### 打开先看总览

以前打开是称量表单，其他二十页藏在边栏里。现在打开是总览页：最近算过
什么（点一下就能按原参数重算）、哪些试剂快到期（红色的排最前）、还有
什么在倒计时。三个区块各管一件事，点进去就是对应的页面。

这个首页是**实时**的：在试剂柜加一瓶药、开一个计时，回到总览立刻就在，
不用刷新。

### 试剂柜

一瓶一条：名称、批号、位置、开瓶日期、有效期。临期（一个月内）标橙色、
过期标红色，永远排在最上面——「那瓶抗体还能不能用」从此是一眼的事，
不用翻冰箱再找标签。

### 计时器

台面上同时等几件事是常态：摇床在转、膜在转印、胶在染。这里一人一行、
各自倒数；到点响三声、标签页标题变成提醒，过了点还会**红着往上数**——
超时多久，和还剩多久一样重要。

时间按「结束时刻」计算而不是每秒扣减，所以手机锁屏、切走再回来，读数
依然是对的。

### 记录可以写字、可以打标签了

每条记录多了一个备注栏，写实验现场的话：「溶液浑浊，过滤后定容」。
备注里的 `#标签` 会变成可以点的筛选项——`#失败`、`#重做`、`#对照组`，
怎么顺手怎么来。按 Ctrl+P 搜 `#失败` 就只看失败的记录。

### Ctrl+P：搜一切

功能页的中英文名、别名（打 statistics 也能找到统计页）、历史记录的
摘要和备注、`#标签`——一个框全搜。搜到历史记录按回车直接回放那次计算。

### 备份终于算备份了

JSON 备份现在把**试剂柜和在跑的计时**一起带走，导入时按条目合并；
导出前的确认页也会写明「2 瓶试剂、1 个计时」随行。换设备不再只剩半份数据。

### 还有

- 删除和清空改成两段式确认（先变红问「确定？」，再点才执行），误触零代价。
- 记录多时列表先显示 50 条，往下滚动按需展开。
- 修了四个只有真实使用才会撞上的问题：备份文件名可能差一天、旧版保存过
  底栏顺序的用户看不到新首页、导入带试剂的备份时报错、仪表盘对个别记录
  显示代码而不是名字。
