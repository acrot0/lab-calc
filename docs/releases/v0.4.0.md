## 先把边界写清楚

这一版加的东西里最重要的不是功能，是那句「**不可用于临床、诊断或生产**」。

首次打开会显示完整的使用须知，之后可从页脚重新打开。须知里写明的是**具体的**模型局限——理想溶液、无活度系数、无温度校正、等当点附近是近似值——而不是含糊地说一句「有局限」。一个看起来权威的计算器会被信任到超出它应得的程度，这份须知就是用来补上那个落差的。

页脚常驻同样的限制声明，每一屏都在。

## 深色 / 浅色 / 跟随系统

三态而不是二态开关：系统偏好始终可达，不必先清掉存储。

配套的是设计 token 系统——间距、字号、层次、动效、颜色全部做成自定义属性，所以浅色主题是第二组 token，而不是第二份样式表。

## 修掉浅色主题下看不见的坐标轴

滴定曲线的画布把深色网格线写死了，于是浅色主题下网格线和轴标签几乎不可见。Canvas 读不到 CSS 自定义属性，所以配色改为传入并记忆化。

## 首次运行流程

须知确认一次后不再显示。**存储不可用时重新显示，而不是跳过**——重读一遍警告是安全的失败方向。
