## 1.3.0：手机上的导出，以前是没用的

这一版不讲新功能。讲一件**你多半已经踩过但没意识到**的事：在手机上点导出，
文件根本没出来。

以及三处会在你不注意时把记录弄丢的地方。

### 手机导出修好了

**之前**：导出按钮点了，什么都没发生。没有文件，没有报错，没有任何提示。

**原因**：网页和手机用的是同一段代码——造一个文件、造一个下载链接、点它。
浏览器上这就是下载。但安卓应用里跑的是 WebView，而 WebView **不支持**下载链接，
点下去既不报错也不保存。这是安卓 WebView 一直如此的行为，不是这次改坏的。

**影响比它听起来大**：你的记录全部存在这台设备上，导出是它们**唯一**能离开的途径。
导出没用，等于这些记录既备份不了、也搬不到新设备——而多数人用的正是手机端。

**现在**：手机上点导出会弹出系统分享面板，你可以存到「文件」、发给自己、
或者直接分享到网盘和聊天软件。电脑和网页端不变，仍是直接下载。

所有导出都修了：CSV、Markdown、Excel（两种视图）、**JSON 备份**，以及
「存为图片」和主题文件导出。

### 记录写不进去时，现在会告诉你

存储空间满了、或者浏览器不允许写入时，记录会**停止保存**——
而界面上原来没有任何迹象：新算的记录照常出现在列表里，直到你下次打开，
列表是空的，且没有任何解释。

现在会有一条常驻横幅：「历史已停止保存」，旁边一个「导出备份」按钮。
它可以恢复：空间腾出来之后下次写入成功，横幅自己消失。

### 三处会悄悄丢掉记录的地方

1. **已删记录没有上限。** 「清空全部」会把每条记录留一份副本（这是为了让你能恢复），
   但副本原来没有数量上限——实测清空十次就吃掉 2 MB，而浏览器给的总额度约 5 MB。
   现在保留最近 300 条。**这条上限和「在用记录」的上限彼此独立**，
   删得再多也不会挤掉你还在用的记录。
2. **记录满 500 条后，已删记录会被整体丢弃。** 修好第 1 条时发现的：每次新记录
   都会把整个列表按 500 条截断，已删的那部分跟着一起没了——回收站变空、
   「恢复」无可恢复、备份导出也不含它们。没有任何地方报错。
3. **JSON 备份现在有确认界面。** 它不是表格，所以不按表格预览——它告诉你
   这次会带走多少条在用记录、多少条已删记录、文件多大，以及一句话：
   这个文件可以在「导入」里还原，换设备也靠它。

### 关于「数据存在哪」，现在说清楚了

首次运行须知原来五条全是关于**算术**的——多精确、什么没建模、什么时候别信。
没有一条说你的记录存在哪、什么时候会没。加了第六条：

> 所有记录存在这台设备上，不上传任何服务器。清理浏览器数据、使用无痕模式或
> 磁盘空间不足时，浏览器可能清除它们，本应用无法阻止。请定期用「导出 → JSON 备份」
> 存一份到别处。**iOS 上另有系统限制：超过 7 天不打开，系统会自动清除网页数据**
> ——请先把本应用添加到主屏幕再使用。

安装提示也跟着改了。原来写的是「装到主屏幕后可以离线使用」——那是次要理由。
**iOS 上装到主屏幕的真正理由是：不装，Safari 会在 7 天后清掉你的网页数据；
装了的不受这条限制。**

这一段同时写进了导出的文件里。导出是那个会离开本机、六个月后被别人打开的东西，
所以「这份文件可能是唯一一份」这句话必须跟着它走。

### 全部实测

- 测试 **2691 通过 / 135 文件**（上一版 2603）
- `npm run verify` 全绿（含署名检查：作者只有 acrot0）
- 五处导出统一走同一条路：有测试断言**没有**任何一处再自己造下载链接，
  否则下次加导出时又会照抄那个在手机上不工作的写法
- 「写入失败 → 横幅出现 → 写入恢复 → 横幅消失」用挂载真组件的方式测过

### Android 签名指纹

本版 APK 用正式密钥签名，与 1.0.0、1.1.0、1.2.0 **同一把**，可直接覆盖安装
（`versionCode` 10200 → 10300）。核对下载到的包是否出自本项目：

```
apksigner verify --print-certs lab-calc-1.3.0.apk
```

SHA-256  62:10:CE:17:86:74:A0:85:1D:77:5D:EB:42:88:1A:37:BE:20:78:B9:37:60:C2:5E:BF:9B:5E:F5:92:7C:CD:08

指纹一致即同一签名，不一致则任何来源都不该装。
