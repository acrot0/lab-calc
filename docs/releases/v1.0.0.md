## 1.0.0：这个计算器现在会替你记住「怎么配的」

前面九个版本都在把算术做准。这一版做的是另一件事：**让一次计算在你离开之后还有用。**

一周后想复现上周那份缓冲液，此前你只有两条路——翻实验记录本，或者重算一遍并祈祷
自己记得当时的浓度。这一版把第三条路补上了：**每次计算都留下了一条能照着做的记录**。

### 记录字段由你定，不再是我们写死的三个

以前的记录只能带「实验号 / 用途 / 操作人」三个固定字段，写死的。有用户反馈说自定义
不够用——确实不够，那不是自定义，那是三个填空题。

现在字段是**全局模板**：增、删、改名、改类型（文本 / 数字 / 日期 / 下拉）、设默认值、
标必填。更关键的是**时机**：

- **记录前**就能预设——配一系列溶液时，实验号自动带进去，不用每条手填；
- **记录后**仍可改——填错了随时补，不是"重录一条"；
- **停用不等于删除**——停用一个字段，老记录里已经填的值**不会丢**，只是新记录不再问。
  这条是刻意的：一个把历史数据一起清掉的"自定义"功能，用户第一次用就会失去东西。

### 误触清空现在有当场反悔的机会

「手滑点了全部清除，记录没了」——这条反馈我们查了：**记录其实没被销毁**，它们进了
回收站，能恢复。问题是**当时看不出来**：列表一下空了，说明在折叠区域里，而人不会在
惊慌的时候往下翻。

现在清空或删除后，列表上方立刻出现一条撤销提示，写明清掉了多少条，8 秒内点一下就
全回来。回收站保留——那是长期的退路，这条是当下的。

### 导出从「数据」变成「能照着做的东西」

以前的导出是原始数据：输入列加结果列。那是给机器看的。

- **配方卡**：称量、稀释、缓冲液、梯度稀释四类计算，Markdown 导出会附上操作序列——
  「称取 NaCl 固体 14.61 g → 转移至 500 mL 容量瓶 → 加去离子水至刻度，摇匀」。
  只给这四类，因为只有这四类真的是**手上的动作**；给能斯特方程编一套步骤，编出来的
  东西会有人照着做。
- **出处表头**：软件版本、导出时间、记录条数、数据格式版本。一份贴进论文附录的表格，
  半年后必须能说清自己从哪来。
- **导出前预览**：先看列清单、行数、前三行，再决定下不下。详细视图有 52 列——点下去
  才知道有多宽，正是预览要解决的问题。

### 每个页签一键示例

20 个页签此前都开在一张半空的表单上。评审、学生、第一次用这个页签的人，都得先自己
编一个实验才看得到它做什么——这是最容易劝退人的一步。

现在顶栏有一个「示例」按钮，点一下填好并算出结果。数字都是台面上真会做的事：0.9%
生理盐水、1:1000 抗体稀释、0.1 M 醋酸滴定。**编造的数字教错东西**，所以没有一个是编的。

### 图表会自己画出来

七张图此前都是瞬间画完——曲线、等当点、Km、共晶点、读数线在第一帧全部出现，
读者第一眼看到的是答案而不是推导。

现在曲线从左侧生长，**所有标注都等扫描线到达它的横坐标才出现**。等当点标记在曲线
走到那里之前不画：一条标着"拐点在这里"的虚线悬在空网格上，是剧透不是图表。

主结果数字也改成逐位揭开。**没有用从 0 滚数**——滚数会在 300 毫秒里显示一串错误数值，
截一张图或逐帧回放，就是一张本应用显示过、却从未成立的读数。遮罩帧不含数字，
不可能被误读成测量值。

### 结果可以存成图片

一份计算结果是文件——表格、备份、打印报告——都不适合丢进群里。现在每个结果下面有
「存为图片」：1200×675 的卡片，含摘要、结果、单位和**出处**。出处那行不是可选项，
一张离开应用却不说明来源的卡片，就是群里一个没有出处的数字。

### 手机端

**Android 版改用正式发布密钥签名**（此前是调试密钥）。证书 `CN=acrot0`，RSA 4096，
有效期到 2056 年，指纹印在 README 里。这不是格式声明，是**这个包的身份**：拿着密钥的人
可以发布一份所有已安装副本都会当作正版接受的更新，而 Android 没有吊销机制。

调试密钥能装能用，但**不能覆盖正式包**——从这一版起，以前装的调试版需要卸载重装一次，
之后就能正常更新了。

### 全部实测

- 测试 **2412 通过 / 120 文件**（上一版 2055）
- 三个平台 CI 全绿；`npm run verify` 含署名检查（作者只有 acrot0）
- 20 个页签在浏览器里逐个点过示例、点过计算：零报错
- APK 是 release 签名，`apksigner verify --print-certs` 指纹与 README 一致
- 桌面端更新通道指向本次发布，`.sig` 已生成

### 提醒

**本工具仅供教学与学习**，不可用于临床、诊断、生产或任何有法规要求的场景。
活度校正只在 I ≤ 0.5 mol/L 内可信；CO₂ 溶解、溶剂体积收缩、络合平衡都未建模。
任何实际配制前，请与教材、药典或试剂说明书**对照核对**。

---

**升级方式**：网页版刷新即是最新。桌面端在设置面板点「检查更新」。
Android 端因签名更换，需卸载旧版后重新安装一次——**之后版本可以正常覆盖更新**。
