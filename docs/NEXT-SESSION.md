## 6. 环境陷阱（**会浪费大量时间，务必先读**）

| 陷阱 | 说明 |
|---|---|
| **Git Bash 裸 `find`** | 命中 Windows `find.exe`，**静默返回空**。用 `git ls-files` 或 node |
| **Bash 工具时区是 GMT** | 系统 +0800，差 8 小时。写日志时间戳会错 |
| **node 的 `/tmp`** | 映射到 `E:\tmp`，不是 Git Bash 的 `/tmp` |
| **GitHub 直连不通** | 必须 `git -c http.proxy=http://127.0.0.1:7897 -c https.proxy=http://127.0.0.1:7897` |
| **`gh api` 路径改写** | Git Bash 会改写路径，需 `MSYS_NO_PATHCONV=1` |
| **Playwright 截图** | 落盘到工作区根的 `.playwright-mcp/`，不是 lab-calc 下的 |
| **heredoc 吃反斜杠** | 写含正则的脚本用 Write 工具，不要用 `cat <<EOF` |
| **Python 控制台 GBK** | 打印非 ASCII 会崩，用 `PYTHONIOENCODING=utf-8` |
