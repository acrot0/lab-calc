# 插画系统

本文件是插画的**唯一真相源**。改插画前先读这里；改完若与这里不符，改的是文档还是代码，先决定清楚。

---

## 1. 为什么需要一份规范

`Illustrations.jsx` 第一版有 11 档线宽：1.2 / 1.4 / 1.5 / 1.6 / 1.8 / 2.0 / 2.2 / 2.4 / 2.6 / 3.0 / 3.4。

每一档单独看都合理——某个地方粗一点更好看，就调粗一点。合起来的问题是：**相邻比值全在 1.07–1.17:1 之间**，而人眼分辨线宽差异的阈值大约在 1.5:1。11 档等距线宽在视觉上等于**没有层级**。

这不是审美问题，是**信息问题**。技术制图里线宽是承载结构的：

> 「单一粗细不给读者任何线索说什么重要。两种开始区分结构与细节。三到四种才能一眼读出深度、什么被剖开、什么在后面。」
> —— 建筑制图线宽规范

ISO 128-2 规定线宽从 0.18/0.25/0.35/0.5/0.7/1.0/1.4/2.0 mm 这个阶梯里取，且**粗细分界至少 2:1**。这套规范的谱系可以追到美国专利局制图标准——实验室器皿正在这个谱系里。

所以：**三档线宽，比值 2:1。**

## 2. 三档线宽

| 档 | 值 | 画什么 | 为什么 |
|---|---|---|---|
| **粗** | `2.4` | 玻璃外轮廓 | 物体的边界。读者先看轮廓才知道这是什么 |
| **中** | `1.2` | 液面、刻度线、结构分隔 | 器皿**内部**的读数与分界 |
| **细** | `0.6` | 高光、气泡、纹理 | 只影响质感，不影响识别 |

比值：2.4 : 1.2 : 0.6 = **4 : 2 : 1**，相邻 2:1，满足 ISO 128-2。

**允许的例外只有一种**：某个元素需要比「粗」更强调时，用 `3.6`（再乘 1.5）。出现这个值意味着图里有真正的焦点，一图最多一处。

### 禁止

- ❌ 1.2 与 1.4 并存——比值 1.17，读者分辨不出，等于白加一档
- ❌ 用线宽做「微调好看」——那是配色和间距的活
- ❌ 超过 4 个不同线宽值——超过就不再是层级，是噪声

## 3. 颜色

**全部走 CSS 变量，禁止写死颜色值。**

| 用途 | 变量 |
|---|---|
| 玻璃轮廓 | `var(--accent)` |
| 玻璃内部渐变 | `var(--accent)` + `stopOpacity` |
| 液面填充 | `var(--accent)` + `opacity` |
| 纸张/固体 | `var(--surface-3)`、`var(--surface-2)` |
| 线条、文字 | `var(--text-dim)`、`var(--text-mid)` |
| 高光 | `white` + `strokeOpacity`（唯一允许的字面色） |

这样一份插画服务 10 套主题 + 深浅跟随，不需要每套主题一份素材。

**为什么不用 Anthropic 那套暖陶土色**：那是写死的颜色。10 套主题（含 Gruvbox、Solarized 这类色相差异很大的）下会有一套颜色不协调。取它的**形态语言**（笔触、留白、圆头端点），不取它的颜色。

## 4. 真实比例

器皿不是随便画的形状，画错会教错。可核对的数字：

| 器皿 | 比例 | 来源 |
|---|---|---|
| 容量瓶（100 mL A 级） | 高:最大径 = **3.26 : 1**；颈外径:最大径 = **0.28 : 1** | 实测规格 7.5″ × 2.3″ × 0.65″ |
| 容量瓶（通用） | 梨形，平底，长而窄的颈，**单一刻度环** | ISO 1042 / ASTM E288 |
| 滴定管 | 长直管 + 旋塞，刻度**自上而下递减** | ISO 385 |

**容量瓶的颈为什么必须细长**：这不是造型，是计量功能。颈内液面高度的小变化对应极小的体积变化——宽颈会让「定容到刻度」失去意义。画一个短粗颈的容量瓶，等于画了一个不能定容的容量瓶。

**容量瓶只有一条刻度线**（TC，定容）。画多条就画成了量筒。这个区别是实质的：多条刻度意味着「量一个范围」，一条意味着「定一个精确体积」。

## 5. 每张插画必须有的三件事

第一版注释里写对了，这里作为硬规则固定下来：

1. **玻璃上的渐变** — 真实玻璃不是均匀色。一侧受光、一侧转暗
2. **有液面的液体** — 填充停在硬线上读作「形状」；顶端有一条更亮的带读作「液位」，那才是化学家认的东西
3. **地面阴影** — 每件东西都放在某个东西上。一个柔和的椭圆消掉「漂浮贴纸」感

## 6. 命名与布局

- 组件名 `Art<用途>`，导出，放在 `src/ui/components/Illustrations.jsx`
- 每个组件**顶部调用一次** `useGradientId()`，绝不写在 JSX 表达式里（Rules of Hooks）
- 渐变 id 必须每实例唯一，否则第二个实例的渐变被忽略、静默用第一个的颜色
- 全部 `aria-hidden`——插画是装饰，含义由旁边的文字承载

## 7. 守卫

`test/illustration-system.test.mjs` 强制：

- 线宽只能取自 `{0.6, 1.2, 2.4, 3.6}`
- 任一文件内不得出现两个比值 < 2:1 的线宽
- 不得出现写死的颜色值（`#xxx`、`rgb()`、`hsl()`），`white` 除外
- 每个 `Art*` 组件恰好调用一次 `useGradientId()`
