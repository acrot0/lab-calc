# Lab Calc

实验室溶液计算器 —— **每次计算自动留存，随时可查可重算。**

**在线使用：<https://acrot0.github.io/lab-calc/>** （无需安装，数据只存在你自己的浏览器里）

```bash
npm install
npm run dev      # 开发
npm run build    # 构建到 dist/，纯静态，可直接托管
npm test         # 90 个测试
```

---

## 为什么做这个

溶液计算器遍地都是，但它们有个共同点：**算完就没了。**

一周后想知道「上次那个缓冲液怎么配的」，你只能翻实验记录本、翻聊天记录、或者重算一遍。而重算意味着重新输入所有参数，还要担心记错了浓度。

电子实验记录本（ELN）能解决，但它太重了——要建项目、选模板、填表。为一次两行算式付出这个代价不值得。

**中间那层是空的：一个计算器，顺手把每次计算留下来。**

这正是本项目的全部差异化所在。算术部分是标准教科书公式，谁都能写对；**留存**才是那个没人做的东西。

## 功能

| 标签页 | 算什么 |
|---|---|
| **称量配制** | 配一定浓度/体积的溶液要称多少克固体 |
| **稀释** | 从母液配目标浓度，取多少母液、加多少溶剂 |
| **缓冲液** | Henderson–Hasselbalch：目标 pH 下的酸/碱配比 |
| **梯度稀释** | 逐级稀释系列，每管取哪一管、取多少、加多少溶剂 |
| **pH 计算** | 弱酸/弱碱溶液的 pH（含常见缓冲体系 pKa 预设）|
| **百分比配制** | w/v 百分比与摩尔浓度互转，超溶解度时警告 |
| **滴定曲线** | 弱酸-强碱滴定曲线，标注等当点体积与 pH |
| **单位换算** | 质量 / 体积 / 浓度单位互换 |

历史记录可**导出为 CSV**（Excel 可开，含 BOM 防中文乱码）或 **Markdown**（直接贴进实验记录本）。

历史记录面板支持**搜索**（按化学式或数值）和**一键重算**（还原参数并跳转到对应标签页）。

## 设计取舍

**未知元素报错，不静默跳过。** `Xx2O` 会报错而不是当成 2 个氧。静默跳过会给出一个看起来对、实则错的摩尔质量，而用户没有机会发现。

**拒绝不可能的操作。** 目标浓度高于母液时，稀释计算会报错——那是稀释做不到的事。返回一个数字会让人照着配出一份错误溶液。

**缓冲范围会提示。** Henderson–Hasselbalch 对 1000:1 的配比照样算得出 pH，但那个缓冲液几乎没有缓冲能力。算式没错，缓冲液没用——所以会警告。

**主结果不用等宽字体。** 试过，弃了：等宽字体下小数点是颗极淡的点，`14.61` 看起来像 `14 61`。实验室里看错小数点是实质问题，不是审美问题。改用 Inter 的 tabular figures，列对齐且小数点清晰。

## 数据

- 原子量：IUPAC 2021 标准原子量
- 所有计算为纯函数（`src/calc/`），无 I/O，可独立测试
- 历史记录存 `localStorage`，**不上传任何数据**

存储不可用（Safari 隐私模式、配额满）时自动降级到内存，计算功能不受影响，只丢历史。

## 结构

```
src/
├── calc/          纯计算函数，无副作用
│   ├── solution.mjs   分子量、称量、稀释
│   └── buffer.mjs     缓冲液、梯度稀释、单位换算
└── ui/
    ├── App.jsx        界面
    ├── history.mjs    历史记录（存储接口注入，便于测试）
    └── styles.css
```

`history.mjs` 接受注入的存储对象而非直接访问 `localStorage`，所以历史逻辑能在 Node 里完整测试，不需要浏览器环境。
